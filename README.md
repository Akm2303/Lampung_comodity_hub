# 🌾 Lampung Agri Commodity Hub

Digital Agriculture & Export Operating Platform untuk Lampung.

## 🏗️ Architecture

| Layer | Technology |
|-------|-----------|
| Frontend | PHP 8.2 + HTML5 + CSS3 + Vanilla JS |
| Backend API | PHP (native) |
| ML Service | Python + FastAPI + XGBoost |
| Database | SQLite (internal) |
| Maps | Leaflet + OpenStreetMap |
| Charts | Chart.js |
| Container | Docker Compose |
